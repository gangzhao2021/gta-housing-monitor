## 提案与原因

| 调整 | 原因 |
| --- | --- |
| HPI 为主指标及全宽主图，成交与供需置于第二层 | 先回答房价走势，再解释交易和供需背景 |
| 白底、留白分组、不加图表外框 | 延续用户接受的简洁方向，减少装饰线 |
| 语言切换无底色，页眉两端对齐 | 避免此前底色和文字偏移问题；保留英文品牌名 |
| 曲线统一实线、图例用同色长线段 | 避免虚线被误读为预测，保证图例和曲线对应 |
| 地区转售默认收起，保留明显展开入口 | 减少首页展开内容；不删除地区功能 |
| 手机端依次展示主图、成交与供需 | 维持阅读宽度，避免双栏挤压 |
| 保留原位置的纵轴单位和指标解释入口 | 不重复此前被否决的单位排版实验 |
