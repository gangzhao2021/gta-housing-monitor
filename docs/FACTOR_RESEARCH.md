## 1. 已明确的方向与候选边界

- 用户明确希望**横向寻找类似油价的外部影响因素**，覆盖需求、融资、人口流动、供给、持有成本及预期等路径，不把研究范围缩成油价下游的材料／运输成本。

## 3. 参数的角色与重复信息

候选可作为背景解释、事件注释、情景输入或预测特征；允许保留研究但暂不展示，不因进入本文就自动添加首页曲线。

同一影响链上的多个指标可以共同帮助解释，但不能当作独立“投票”。例如能源价格、通胀、债券收益率和按揭利率可能包含同一冲击；材料价格与建筑造价总指数也可能重叠。比较新增变量相对已有核心变量的额外信息，而非按指标数量累计信心。

对成本冲击分别分析需求与供给两条路径和不同期限：成本／融资上升可能削弱当前购买力，也可能减少未来建设；最终方向依当地库存、收入、用途和时间而变。相关性、传导解释和可预测性分别表述，不能据同期相关性宣称因果。已包含住房费用的物价指标须说明反馈关系；如研究剔除住房的物价，只采用可核验的官方口径或有权重依据的算法，不做简单指数相减。

### Absorption rate 的口径

- 若定义为同期间、同范围的当月成交 ÷ 月末有效挂牌 × 100%，且两者均为正值，它等于 `100 / moi_raw`，不新增独立供需证据。零分母时无定义，不能输出无穷大或替代值。
- 若某来源用成交 ÷ 新增挂牌 × 100% 并称其 absorption rate，则按本项目定义归为 SNLR；须先读公式，不能只按英文名称合并。
- 上述两个比率都不是“当月挂牌的这些房屋有多少被卖出”的逐套追踪概率。
- CMHC Market Absorption Survey 的新房吸纳是已售且完工，不能替代签约预售；Ontario 未吸纳库存的方法审查提示及来源核验状态见[来源覆盖](SOURCE_COVERAGE.md)。

## 4. 采用前的调查记录

每个具体候选至少补齐以下内容，缺资料可形成“暂不可用”的有效结论：

1. **定义与用途**：具体变量、单位、币种／倍率、调整方法、作用路径、适用地区／物业、预期作用期限；标注是背景、事件、情景还是预测候选。
2. **原始来源与可维护性**：发布机构、表号／系列、原件、频率、历史长度、地区边界、质量／抑制、许可和再分发条件、可持续获取方式；研究文章链接不等于已确认可自动采集的数据接口。
3. **时间与版本**：所属期、正式发布日期、修订可用时点及证据、首次采集时间。月度研究只使用判断日已可获得的数据；年度／季度值不插值成观测到的月度事实。
4. **独立信息与限制**：与已有指标的重叠、反向因果可能、代理指标的偏差、不同经济阶段的符号变化、缺值处理；不预设固定权重和买卖阈值。
5. **采用决定**：保留候选、暂不可用、作为背景展示、进入预测实验或排除，并记录理由、日期和复查条件。建议优先核查地区贴近、定义清楚且有可靠历史的候选；具体先后尚未逐项确定。

政策／事件另记录：公告日、生效日及终止／修订日、司法辖区、适用对象和物业、提案／已通过／已生效／撤回状态、旧规则与新规则、原始公告和版本。预测实验不得把尚未公告的未来政策提前用于历史判断，也不能用今天的规则覆盖整段历史。

纳入预测须衔接 R0–R3：先冻结目标与比较基线，再检验新增变量的样本外增量价值。候选很多而样本短时需控制反复筛选和调参，保留失败／弃用结果；训练中选择变量、变换、滞后和权重，留出的未来区间用于检验。没有可靠历史版本时说明研究近似及限制，不发布确定性预测。


### 2026-09-26 采用前调查记录（四项，只调研）

#### A. TRREB 季度 condo 经 MLS 实际签约租金

1. **定义与用途**：季度内经 TRREB MLS 报告租出的 condominium apartments，按卧室数和来源地区的平均签约租金，CAD/月；租约数与新增租赁挂牌另列。属租住替代与投资现金流背景，不能当 Rentals.ca 挂牌均值或 CMHC 存量租约均值。季度流量、不插值月度，季度与 YTD 单独处理。
2. **原始来源与可维护性**：[官方档案](https://trreb.ca/market-data/rental-market-report/rental-market-report-archive/)目前列 2015Q1—2026Q2；[Q2 2025 PDF](https://trreb.ca/wp-content/files/market-stats/rental-reports/rental_report_Q2-2025.pdf)可直接读取。[当前报告页](https://public.trreb.ca/market-data/rental-market-report/)有租约数和房型租金。未来按档案链接保存 PDF/SHA、按期核对版式与总计；不是现有 Market Watch extractor。网页免费、无 key；版权与再分发需按 TRREB 条款核查，免费读取不等于获准复制整份报告。档案列表存在不代表已验证每份文件与地区范围。
3. **时间与版本**：所属季度与实际发布日期分开，保存报告原版、下载时点和后续修订版。已发现 Q2 2025 原报告总租约 20,417，而 Q2 2026 当前网页的上年比较写 20,396；须保留原始期与比较期的版本差异，不静默覆盖。尚未建立逐期发布时间证据；网页统一更新时间不能替代每期发布日。
4. **独立信息与限制**：比挂牌租金更接近已达成租约，但只代表经 MLS 报告的 condo 租赁，未覆盖所有私人或专建出租住房。房型／地点／品质构成变动可改变均价；季节性和小样本需要说明，不用均价涨幅当同一物业租金涨幅，也不预设预测权重。
5. **采用决定**：**建议接入**（2026-09-26）。新增实际租赁信息有用，官方档案可维护。**2026-10-07 已接入**：`housing.trreb_rental` 解析 2022Q3—2026Q2 共 16 份报告的 All TRREB Areas 公寓行（挂牌、租出、四类房型均租），房型租出量须合计等于总租出；各季原发布版入库，不以后续报告的上年栏覆盖。仅作背景最近值展示，再发布许可仍待审查，Sites 发布前须确认。

#### B. CMHC HMIP：Toronto 各 census subdivision 历史空置率

1. **定义与用途**：CMHC Rental Market Survey 的专建出租市场空置率，百分比、年度，按 CSD／卧室类型／结构类型选择；不能拆分已有组合调查区去反推 Markham、Vaughan 等单城。用于年度空置背景，不能生成月度空置率。
2. **原始来源与可维护性**：[官方 HMIP](https://www03.cmhc-schl.gc.ca/hmip-pimh/en)、[CMHC 租赁数据目录](https://www.cmhc-schl.gc.ca/professionals/housing-markets-data-and-research/housing-data/data-tables/rental-market)提供 vacancy/CSD 入口。HMIP 表界面可提供 CSV、CSD 和历史显示选项；本轮确认一般入口和其他 CMA 示例，但**没有完成 Toronto 每个 CSD 的实际 CSV 导出**，不能声称已取得稳定批量 API 或统一最早年份。需保留原 CSV、选择参数、地理代码、结构／卧室和质量图例；授权以 CMHC 使用条款为准，地图服务不等于空置率数值 API。
3. **时间与版本**：所属年／调查月、报告发布日、下载日期分别保存。要逐年核对边界 vintage 和修订，不把今天的历史导出视为当年可见版本。当前不填虚构首次发布时间；CSD 有无完整连续历史仍待样本核查。
4. **独立信息与限制**：CSD 与 CMHC 自定义调查区不同，名称相似不能互换。小样本会有 `**` 抑制和质量等级；抑制不是零、不是上一年值。各年边界／调查总体可能改变，且年度频率不支持短期房价信号。
5. **采用决定**：**保留候选**（2026-09-26）。不判定“来源不存在”；待成功导出 Toronto、Markham 等至少两个 CSD、两个年份，并核对质量与下载参数后再决定接入。现有 CMHC 调查区数据不变。

#### C. Toronto Open Data：building permits / development applications

1. **定义与用途**：City of Toronto 行政记录，含许可申请／签发／完成日期、状态、工作类型、创建及损失单位；开发申请另含申请类型、提交时间、父子文件关系和位置。是审批／项目管线背景；许可申请不是开工、申请单位不等于最终交付。覆盖市界，不是整个 CMA/GTA；本轮不抓取联系人用于产品展示。
2. **原始来源与可维护性**：[在办许可](https://open.toronto.ca/dataset/building-permits-active-permits/)、[已结束许可](https://open.toronto.ca/dataset/building-permits-cleared-permits/)、[开发申请](https://open.toronto.ca/dataset/development-applications/)。官方 CKAN 根地址 `https://ckan0.cf.opendata.inter.prod-toronto.ca/api/3/action/`；本轮匿名 `package_show` 与 `datastore_search?limit=1` 成功，无 key。资源 ID：在办 `6d0229af-bc54-46de-9c2b-26759b01dd05`、2017 起已结束 `a96c0ba4-3026-402b-b09d-5b1268b8f810`、开发申请 `8907d8ed-c515-4ce9-b674-9f8c6eefcf0d`。另有已结束许可 2000—2016 CSV。许可门户说明 1999-10-01 前申请可能不完整。门户标注 Toronto 开放许可，但本轮 CKAN `license_title` 返回 “License not specified”，须保留门户授权证据并核对具体资源；不能只看 API 字段就断言无使用限制。
3. **时间与版本**：目录刷新时间不是每条记录首次公开时间；申请、签发、完成各自保留。定期快照可从现在积累状态版本，不能倒推出过去某日已知状态。在办记录转到已结束集合时要保持可追踪 ID；每天刷新不能当作每天新建量。
4. **独立信息与限制**：本轮字段确认许可有 `PERMIT_NUM`、`REVISION_NUM`、`DWELLING_UNITS_CREATED/LOST`；开发申请有 `APPLICATION#`、`PARENT_FOLDER_NUMBER`，样本 schema 未见标准化新增住宅套数字段。申请修订、多个许可与父子申请都可重复统计同一项目，不能按记录条数推住宅供应，也不能把描述文本猜成套数。当前快照有幸存／状态迁移偏差；缺失坐标和旧资料还需质量审计。
5. **采用决定**：**保留候选**（2026-09-26）。API 可用，但项目去重和历史状态口径尚未解决；优先使用已经接入的 StatCan 住宅许可单位作总体背景。待完成稳定主键、分页完整性、生命周期去重及单位字段覆盖审计后，才实施市级地图或项目管线。

#### D. StatCan 国际／省际净迁移季度数据

1. **定义与用途**：Canada／各省及领地的季度人口流量，人；选择 Ontario。省际净迁移为迁入减迁出；国际净迁移须按官方 components 定义处理移民、移出／返回及非永久居民变化，不能只用永久居民移民人数。保留季度，可负值、不季调、不拆成虚构月度数值；用途为省级需求背景。
2. **原始来源与可维护性**：[17-10-0020-01 省际迁移](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1710002001)、[17-10-0040-01 国际迁移](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1710004001)，两表由[官方季度人口看板](https://www150.statcan.gc.ca/n1/pub/71-607-x/71-607-x2019036-eng.htm)明确列为输入。支持官方 CSV/WDS，无需 key，StatCan 开放许可需署名；本轮未逐项下载 Ontario component 全历史，具体 vector 与各分项起点待核验。不是已有年度 CMA 人口变动表 17-10-0149 的季度替代品。
3. **时间与版本**：省际表本轮页面发布日为 2026-09-23，相关发布为 2026Q2。须记录每个季度参考期、初步／更新估计和修订时点；今天重取的历史序列可能重估，不可当作历史首次发布值。官方看板提示到 2021Q2 为止，总人口变化与分项和之间还涉及 residual deviation，不能强制相加相等。
4. **独立信息与限制**：Ontario 流量无法直接分摊给 Toronto 或个别城区。身份转换不一定是新进入本地的人；净额也不能体现 gross flows 和家庭数量。与年度总人口互相关联，不重复当作独立利好票数；与房价有双向地区选择效应。
5. **采用决定**：**建议接入**（2026-09-26），先作为 Ontario 季度背景。实施前核对完整分项和公式、负值与版本，保留官方直接净额时优先使用；严格样本外回测须另补真实可用时点。本轮仅调研，不写该来源导入代码。

## 7. 首批背景数据的实施状态

2026-09-24 对四份官方来源真实取数并保留原件：EIA WTI Cushing、BoC `M.ENER`、BoC `FXMUSDCAD` 和 StatsCan Toronto 住宅建筑造价综合指数。共新增 **182 条数值观测、四份登记原件**；第二次刷新四源均为 `unchanged`。私有库保留背景历史；管理端数据页和只读展示端“经济与供给”均列四项最近值，后者还列期间、单位、地区和来源，未发布四项背景完整历史。当前最新值及完整覆盖见[来源覆盖](SOURCE_COVERAGE.md)。每日周期先处理四个核心来源并在恢复检查后发布快照，再处理四个背景来源、再次核验并二次发布；背景刷新失败会在周期报告中报错，不撤回已成功验证的核心快照。

这四项仅作为背景，不进入领先信号、打分或回测。保留的历史快照可能包含事后修订；本机首次采集日期不等于各期首次公开日期。逐期可用时点仍待 R1 核证，其他候选也未自动纳入采集。
