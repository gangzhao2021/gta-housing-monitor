# 领先信号实验协议（2026-09-26 v1）

本协议冻结第一轮可重复实验，不声明预测有效。机器可读参数见 `src/housing/research_protocol.json`；运行 `.venv/bin/python scripts/run_backtest.py`，私有报告写入 `data/research/latest-backtest.json`。

| 项目 | 冻结定义 |
| --- | --- |
| 判断时点 | 每个观察月最后一天 Toronto 时间 23:59:59 |
| 目标 | TRREB 当月成交量和 HPI 综合基准房价，各预测未来 3／6 月相对观察月的百分比变化 |
| 标签版本 | 有正式证据的首次公布版本；评估时只使用截至报告生成日已经公开的结果 |
| 信息集 | 特征至少滞后一个月；逐版本检查实际公布时间。当地数据库版本号不代表官方修订先后 |
| 实验规则 | t-1 与 t-4 的三个月动量，按预测期比例延续；没有拟合参数，不在样本外反复调阈值 |
| 基线 | 零变化；以 t-13 到 t+h-13 的变化作为滞后一期的季节基线。成交量未季调，不称季调趋势 |
| 中性区 | 成交 ±5%、HPI ±1%；边界归中性 |
| 分割 | 训练截止 2024-08，样本外从 2024-09 开始。至少 12 个在训练截止已成熟且已公布的训练标签，以及 12 个合格测试起点 |
| 缺失 | 不插值；缺历史版本、发布时间证据、已成熟结果或分母非正时排除并记原因 |
| 报告 | MAE（百分点）、方向准确率、误报上涨／漏报上涨数量；同时给不重叠起点子样本，不能把重叠窗口当作独立成功 |
| 采用 | 初始结论为保留实验；短历史单周期结果不自动成为产品预测。外部背景因素的增量效果尚未研究 |

2026-09-26 实际执行：四组实验均为 `not_evaluable`，没有可用的正式历史发布版本证据，没有生成有效性分数。合成数据测试只验证时间门禁、版本排序与计算路径，不能用作真实预测证据。现有 `availability_evidence` 是人工证据引用字段，仍需逐条核验官方公告与对应数值版本；非空文本不是完成证据审查。

下一步：先为历史 PDF／官方修订原件建立可审计证据引用，绑定具体观测版本的公布时间（包括时区与时间精度）。日期只有一天时使用该日结束作为保守可用时点；来源只给当前修订值时保留不可评估。入证后按原协议重跑；如要改规则，新增协议版本，不能覆盖本版或用测试结果倒调。
