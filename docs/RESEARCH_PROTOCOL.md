# 领先信号实验协议（2026-09-26 v1）

本协议冻结第一轮可重复实验，不声明预测有效。机器可读参数见 `src/housing/research_protocol.json`；运行 `.venv/bin/python scripts/run_backtest.py`，私有报告写入 `data/research/latest-backtest.json`。

| 项目 | 冻结定义 |
| --- | --- |
| 判断时点 | 每个观察月最后一天 Toronto 时间 23:59:59 |
| 目标 | TRREB 当月成交量和 HPI 综合基准房价，各预测未来 3／6 月相对观察月的百分比变化 |
| 标签版本 | 有正式证据的首次公布版本；评估时只使用截至报告生成日已经公开的结果 |
| 信息集 | 特征至少滞后一个月；逐版本检查实际公布时间。当地数据库版本号不代表官方修订先后 |
| 实验规则 | t-1 与 t-4 的三个月动量，按预测期比例延续；没有拟合参数，不在样本外反复调阈值 |
| 基线 | 零变化；以 t-13 到 t+h-13 的变化作为滞后一期的季节基线。成交量未季调，不称季调趋势 |
| 中性区 | 成交 ±5%、HPI ±1%；边界归中性 |
| 分割 | 训练截止 2024-08，样本外从 2024-09 开始。至少 12 个在训练截止已成熟且已公布的训练标签，以及 12 个合格测试起点 |
| 缺失 | 不插值；缺历史版本、发布时间证据、已成熟结果或分母非正时排除并记原因 |
| 报告 | MAE（百分点）、方向准确率、误报上涨／漏报上涨数量；同时给不重叠起点子样本，不能把重叠窗口当作独立成功 |
| 采用 | 初始结论为保留实验；短历史单周期结果不自动成为产品预测。外部背景因素的增量效果尚未研究 |

2026-09-26 实际执行：四组实验均为 `not_evaluable`，没有可用的正式历史发布版本证据，没有生成有效性分数。合成数据测试只验证时间门禁、版本排序与计算路径，不能用作真实预测证据。现有 `availability_evidence` 是人工证据引用字段，仍需逐条核验官方公告与对应数值版本；非空文本不是完成证据审查。

下一步：先为历史 PDF／官方修订原件建立可审计证据引用，绑定具体观测版本的公布时间（包括时区与时间精度）。日期只有一天时使用该日结束作为保守可用时点；来源只给当前修订值时保留不可评估。入证后按原协议重跑；如要改规则，新增协议版本，不能覆盖本版或用测试结果倒调。

# 领先信号实验协议 v2（2026-10-07，结果出来前冻结）

v1 保持冻结：TRREB 目标缺正式历史发布版本，仍为不可评估。v2 是新的独立实验，机器可读定义见 `src/housing/research_protocol_v2.json`，在计算任何结果前提交到 Git。

| 项目 | 冻结定义 |
| --- | --- |
| 设计 | 准实时：使用最新版本数据并施加保守的发布滞后。看得到之后的修订，因此结果是实时能力的**上限**，不是实时回测 |
| 判断时点 | 每月月底（Toronto 时间） |
| 目标 | Teranet–National Bank Toronto 季调指数，自 T−2（视为判断时已知的最新月）起未来 6／12 个月的对数变化（百分比） |
| 候选因素 | Teranet 自身 6 个月动量；Teranet 配对成交量同比；BoC 五年期传统按揭利率 12 个月变化；五年期国债收益率 12 个月变化；Ontario 失业率 12 个月变化；Toronto 开工 12 个月合计增长；Toronto 新房价格指数同比；加拿大政策不确定性指数近三月对数均值。各项滞后见 JSON |
| 模型 | 基准为历史均值（只用判断时已到期的结果）；零变化作参考；每个因素一元 OLS 扩展窗口；各一元预测等权组合 |
| 样本 | 至少 60 个训练观测；样本外自 2010-01 起；分 2010–2019 与 2020 至今两段 |
| 指标 | 相对历史均值的样本外 R²、RMSE、方向命中率；Clark-West 检验（Newey-West，h−1 阶滞后，单侧） |
| 证据规则 | 某模型在某预测期“有证据”须同时满足：全样本外 R²>0、两个子段 R² 都 >0、全样本 Clark-West 单侧 p<0.05。否则记“无证据” |
| 禁止 | 看到结果后改因素、滞后、分段或证据规则；如需修改另立新版本并同时报告本版结果 |
| 采用 | 只作研究证据；不在看板显示信号或预测 |

# 领先信号实验协议 v3（2026-10-07，结果出来前冻结）

在 v2 基础上加入 TRREB 市场平衡类指标（2004-01 起，来自历年 Market Watch 存档，见 `data/research/trreb-history.csv` 的构建与校验）。目标、模型、基准、指标与证据规则与 v2 完全相同，v2 结果继续报告。机器可读定义：`src/housing/research_protocol_v3.json`。

| 项目 | 冻结定义 |
| --- | --- |
| 发布滞后 | TRREB 第 M 月报告视为 M+1 月底才可用，特征最晚用 T−1 月 |
| 三个月口径 | 库存月数 = 三个月在售挂牌合计 ÷ 三个月成交合计；成交／新挂牌比 = 三个月成交合计 ÷ 三个月新挂牌合计 |
| 候选因素 | 库存月数同比（对数）、库存月数相对同月历史常态；成交／新挂牌比同比（百分点）、相对同月历史常态；成交价／挂牌价比同比；挂牌天数同比（对数） |
| 季节性 | 同比或“相对同月历史常态”（只用更早年份、至少 3 年），不用未季调原值 |
| 口径断点 | 早期“平均 % 挂牌价”与后期“SP/LP”公式不同、早期 DOM 与 2020 年后 LDOM 不同，跨口径的同比记缺失 |
| 不纳入 | 成交量同比（TRREB 覆盖范围扩大会造成水平跳变）；2002 至 2003 年中（系统切换） |
| 样本外 | 2011-01 起（满足 60 个训练观测）；分 2011–2019 与 2020 至今两段 |
| 证据规则 | 同 v2：全期与两个子段 R²>0，且全期 Clark-West 单侧 p<0.05 |
