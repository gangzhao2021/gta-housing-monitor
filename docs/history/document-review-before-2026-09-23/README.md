# Toronto Housing Leading Indicator

用于查看 Toronto 周边住宅转售、租赁与住房供给的本地数据看板，面向非技术使用者。

看板读取已保存的 BoC、StatsCan、TRREB、CMHC 官方资料，以及 Rentals.ca / Urbanation 公开挂牌租金报告。当前界面分为“市场总览”“租赁市场”“经济与供给”“月供情景”“数据与记录”五页：

- 月度转售趋势、供需比与 HPI 房型基准价；房型数据追溯到所选月份观测实际引用的原报告。
- 地区租金对比：最多三个地区；月度挂牌与年度 CMHC 分列，原始组合调查区和缺失状态明确标注。
- 月度挂牌租金走势（2022-07—2026-07），以及最新已接入月份的一卧、两卧、三卧报价。
- 2022—2025 年开间、一卧、两卧、三卧及以上和全房型平均租金，对照专建出租公寓与业主出租 condo；另列空置率与来源质量。
- 利率、就业、人口，以及按独立屋、半独立屋、排屋、公寓及其他住宅拆分的建设情况。
- 可调整的月供比较、按当前范围下载 CSV，以及保存含来源版本的本地观察记录。

各页按自己的资料频率选择期间，人口与 CMHC 租赁采用独立年度控制，挂牌租金采用独立月份控制。缺失期间保留空白；同比变化用中性颜色显示，不自动判为利好或利空。月供输入在当前网页会话中切换页面后保留。

当前是公开数据研究工具，尚无经过验证的领先信号或预测能力；页面改版与房型扩展不代表整个预测项目已完成。验收证据、按揭资料延迟、预售来源及历史发布时点等限制见[项目验收表](docs/PROJECT_ACCEPTANCE.md)和[工作交接](HANDOFF.md)。地区、房型与调查口径在相应页面分别标注。

第一版技术路线：Python → SQLite → Streamlit，本地运行，公开数据优先。

术语：MVP 指第一个可使用的版本；季调指排除常见季节波动；回测指使用历史资料检验规则；“领先”是待验证的目标，不是产品名称已证明的能力。
