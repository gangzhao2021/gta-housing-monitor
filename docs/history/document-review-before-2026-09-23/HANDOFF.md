## 当前实现

- Python → SQLite → Streamlit，本地入口 `app.py`，地址 `http://127.0.0.1:8501/`。目录没有 Git 仓库；没有远端部署、定时调度或外部通知任务。BoC／StatsCan已有独立的手动更新入口。
- 五页：市场总览、租赁市场、经济与供给、月供情景、数据与记录。已应用用户认可的 Figma 白底极简设计，横向导航、大幅趋势图、侧向筛选区及蓝／青绿／橙／紫数据配色。
- 中英文选择在页头右侧，与品牌垂直居中对齐；Figma五个现有画板已更新为中文／EN双选，网页使用原生radio而非下拉框。每项44×44px，当前语言蓝字浅蓝底，支持点击及键盘方向键；手机导航可横向滚动。筛选和月供参数在当前会话内保留。
- 指标名称旁 ⓘ 提供中英文影响机制说明：桌面悬停、点击及键盘展开；手机可点击。说明包含适用限制和央行参考链接，不是预测结论。
- 市场总览：HPI 价格主图、成交／挂牌、默认可见的库存月数与成交／新挂牌比趋势、可展开的连续三个月均线、季节热力图、HPI 房型截面与共同基期累计变化及来源下载。
- 租赁：月度挂牌、年度 CMHC、地区对比三个视图。地区视图通过“编辑地区”或位置点地图选择最多三个地区，“口径与时间”控制来源、期间和年度指标；趋势和共同期间变化图同步。位置点不代表统计边界，地区数值不下推到街道。不同来源／地区边界不拼接，缺月不补值；未提供与抑制发布分别解释。
- 经济与供给：利率、就业、建设、人口四节默认连续显示，页内导航可跳转；各节保留独立期间，年度人口独立于月度，建设提供房型分项。
- 月供：按加拿大半年复利换算计算两种利率下的本息，数字和对比图一致；新增固定本金／摊还期的历史月供情景图，按已接入 BoC 按揭利率逐月重算，缺月留空。空输入提示补齐，零本金是有效的零月供。
- 数据与记录：新鲜度、指标定义、源文件、导入运行与本地观察记录；保存不覆盖既有文件，下载保留输入版本与来源。

- 初次功能审计 **46 项测试通过**（含17项页面集成；后续英文图表修复后为47项），覆盖解析、导入幂等与修订、异常批次原子性、来源链、缺失、期间、CSV、中英文、页面／房型切换、月供边界。
