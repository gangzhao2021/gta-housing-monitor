# Toronto Housing Leading Indicator

用于查看 Toronto 周边房价及相关因素的本地数据看板，面向非技术使用者：把住宅转售、租赁、住房供给，以及利率、就业、人口等公开数据放在一起看。

> **当前定位**：公开数据研究工具。领先指标研究（[v3](docs/LEADING_STUDY_V3.md)、[v4](docs/LEADING_STUDY_V4.md)）发现：TRREB 的成交／新挂牌比、库存月数相对同月历史常态，对未来 6–12 个月房价方向有参考意义；利率、就业、开工等宏观因素未达到证据标准（[v2](docs/LEADING_STUDY_V2.md)）。看板上的“市场温度”据此描述当前供需，**不是预测，不构成投资建议**。

技术路线：Python → SQLite → Streamlit，本地运行，公开数据优先；另有静态网页版发布为私有 Claude Artifact。

## 访问入口

以下假设 `.venv` 和私有 `data/` 已准备好；新电脑或只取得代码仓库时，先按[使用指南](docs/USER_GUIDE.md)安装并恢复数据。公开 Git 仓库不包含数据库、原件、口令文件、研究数据或网站数据快照。

- **管理端（8501）**：首次运行 `.venv/bin/python scripts/setup_owner_password.py` 设置本机密码，再运行 `sh scripts/run_owner_local.sh`，打开 <http://127.0.0.1:8501/>。
- **展示端（8502）**：运行 `sh scripts/run_viewer_local.sh`，打开 <http://127.0.0.1:8502/>；使用同一本机密码。
- **网页版（私有 Artifact）**：[GTA Housing Monitor](https://claude.ai/artifact/6kMnQMgJdnwbPuiMC4taXK)，默认仅本人可见。每天 09:20／14:20 的 Claude 定时任务在本机数据更新成功且网站文件变化时自动重新发布（需 Claude 应用开着）。原 Codex Sites 版已停止更新（2026-10-07 暂停其自动化）。

## 更新机制

- 本机 LaunchAgent 每天 09:00 运行更新周期，14:00 再跑一次补救网络失败：核心官方来源（BoC、StatsCan）与 TRREB 月报 → 恢复核验 → 发布展示快照；背景来源、TRREB 季度租赁报告、CBA 按揭拖欠各自独立刷新，失败不影响已核验的核心发布；最后导出网页数据。未完全成功时弹出 macOS 通知。
- 需人工处理：Rentals.ca 月度挂牌租金报告（网站拦截自动下载）、Teranet 房价指数（需填写下载表单，`scripts/import_teranet.py`）。
- 当前数据量：`.venv/bin/python scripts/status_summary.py`。
- 测试：`PYTHONPATH=src .venv/bin/python -m unittest discover -s tests`；网页回归 `npm run test:site`（Node 装在 `~/.local/node`，需 `PATH=~/.local/node/bin:$PATH`；首次运行 `npm install` 与 `npx playwright install chromium`）。

## 看板内容

- **市场总览**：HPI 基准房价（附 TRREB 公布同比）与**市场温度**刻度、成交／新增挂牌／有效挂牌／库存月数、房价走势（2025-04 基期调整在图上标注）、**长期房价走势**（Teranet，1998 年起）、市场温度走势与其后 12 个月 HPI 对照、成交价格段分布；“地区与市镇”默认收起，含市镇成交均价环比地图与地区转售明细。
- **租赁市场**：顶部并排比较同一房型的挂牌、签约与 CMHC 年度租金（公寓／镇屋 × 开间至三卧，缺口径时注明原因）；月度挂牌、签约租金（condo／镇屋）、CMHC 年度调查（含专建出租镇屋）、最多三个地区对比。
- **经济与供给**：全页一个时间范围；四项关键读数附一年前值；利率（2015 年起）、失业、开工与竣工、人口；背景指标分组收起。
- **月供情景**：从房价、首付比例、摊还年限和利率出发，给出月供、压力测试月供、约需家庭年收入和利率敏感度（加拿大半年复利）。
- 每个指标旁 ⓘ 依次说明：是什么、与房价的关系、注意事项。

### 覆盖的数据

| 类别 | 已接入 | 已知限制 |
| --- | --- | --- |
| 价格 | TRREB HPI（按房型）及公布同比；Teranet–National Bank 重复交易指数（Toronto，1998 起） | Teranet 需每月人工下载 |
| 交易与供需 | 成交、新挂牌、在售挂牌、库存月数、成交／新挂牌比、价格段分布；地区明细 | 研究用 2004 年起历史存档仅在本机 |
| 租赁 | 月度挂牌租金；CMHC 年度租金与空置率（含专建出租镇屋）；TRREB 季度 condo 与镇屋实际签约租金 | Downtown 等部分地区无月度数据；2024-09 有 3 个地区缺；独立屋、半独立屋、单间合租无可靠公开来源；CMHC 2022 年前为旧普查边界，未接 |
| 利率与融资 | BoC 政策利率、五年国债、新增固定按揭（2015 年起）、优惠利率、五年期公布利率；Ontario 按揭拖欠率 | 新增按揭利率发布滞后约两个月 |
| 需求 | 就业、人口；Ontario 国际／省际净迁移 | 家庭收入、财富与信心未接入 |
| 新增供给 | 开工／竣工／在建（按房型、按市场类型）、建筑许可、新建完工未吸纳库存、新房价格指数 | 未吸纳库存只含自住与 condo 项目 |
| 外部背景 | WTI、BoC 能源指数、USD/CAD、建筑造价指数、加拿大政策不确定性指数 | 背景参考，未验证对房价的预测作用 |

### 解读时的注意事项

- 月度挂牌租金是房东要价，不是实际签约租金；CMHC 均租同比不是同一套住房的租金涨幅。
- 看板自算同比用各期原发布值，TRREB 公布同比用修订后的上年值，两者可能相差 1 个百分点以上；卡片注明使用哪一种。
- 缺月留空、不补值；不同来源／地区边界不拼接。
- 市场温度描述当前供需，研究样本外只有 2018 年起约 8 年，不是预测。

## 术语

- **MVP**：第一个可使用的版本。
- **季调**：排除常见季节波动。
- **回测**：使用历史资料检验规则；**样本外**指用建模时没用过的历史区间来检验。
- **领先**：待验证的目标，不是产品名称已证明的能力。
- **信息集／修订可用时点**：预测某一时点时，当时实际已公布、可用的数据（含之后被修订前的版本）。
- **TRREB**：Toronto Regional Real Estate Board，多伦多地区房地产局；**HPI**：MLS® 房价指数；指数与基准房价是不同量，页面分别按实际单位展示。
- **SNLR**：成交／新挂牌比（sales-to-new-listings ratio）。
- **BoC**：加拿大央行；**StatsCan**：加拿大统计局；**CMHC**：加拿大抵押贷款和住房公司，年度租赁市场调查的来源。
- **CMA**：Statistics Canada 的人口普查都会区；后缀年份（如 CMA2021）为所依据的边界年份。
- **共同基期**：多条序列使用同一个起点计算累计变化；**共同期间**：比较使用相同的起止期。
- **抑制发布**：来源出于保密或可靠性等原因不公布该数值。
