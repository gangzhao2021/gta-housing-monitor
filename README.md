# Toronto Housing Leading Indicator

用于查看 Toronto 周边房价及相关因素的本地数据看板，面向非技术使用者：把住宅转售、租赁、住房供给，以及利率、就业、人口等公开数据放在一起看。

> **当前定位**：公开数据研究工具，尚无经过验证的领先信号或预测能力；页面改版与房型扩展不代表整个预测项目已完成。

已先在现有 Figma 精简六处页面装饰线，再修改网页样式；图表数据曲线保留。管理端和只读展示端现在都要求本机密码，仅供本人演示。展示快照剔除原件路径、私人记录等字段，但包含代码目录中有数值系列的全部已存历史、各期最新版本；尚未经对外发布审定，也未部署到远端。

第一版技术路线：Python → SQLite → Streamlit，本地运行，公开数据优先。

## 快速开始

以下假设 `.venv` 和私有 `data/` 已准备好；新电脑或只取得代码仓库时，先按[使用指南](docs/USER_GUIDE.md)安装并恢复数据。Git 不包含数据库与原件。

- 管理端：首次运行 `.venv/bin/python scripts/setup_owner_password.py` 设置本机密码，再运行 `sh scripts/run_owner_local.sh`，打开 <http://127.0.0.1:8501/>。默认至少 16 字符；仅本人本机演示可按[使用指南](docs/USER_GUIDE.md)启用 6 字符例外。后续启动只运行启动脚本。
- 展示端：运行 `.venv/bin/python scripts/publish_display.py`，再运行 `sh scripts/run_viewer_local.sh`，打开 <http://127.0.0.1:8502/>；使用同一本机密码。

当前是本机演示方案，两个入口均监听本机地址；本地密码不等于已经完成远程账户授权。停止、改密、导入和备份步骤见使用指南。

**更新与联动现状**：本机每天 09:00 检查 BoC／StatsCan 四个官方来源；报告类仍需人工核验。管理页已有共同筛选与地图联动，市场和经济节的来源表可单选一行切换观察月份；跨页面统一筛选仍未实现，见[实施计划第 6、10 节](docs/IMPLEMENTATION_ROADMAP.md)。

## 看板内容

以下描述完整管理页：读取已保存的 BoC、StatsCan、TRREB、CMHC 官方资料，以及 Rentals.ca / Urbanation 公开挂牌租金报告。界面分为“市场总览”“租赁市场”“经济与供给”“月供情景”“数据与记录”五页，支持中文／EN 切换；指标名称旁的 ⓘ 说明该指标的影响机制与适用限制。只读展示页有前四个主题，但地图、来源细目和部分分析尚未迁入，功能差异见使用指南。

- 月度转售趋势、库存月数、成交／新挂牌比与 HPI 房型基准价，含季节热力图和房型累计变化；房型数据追溯到所选月份观测实际引用的原报告。
- 地区租金对比：最多三个地区，可通过“编辑地区”或地图位置点选择；月度挂牌与年度 CMHC 分列，原始组合调查区和缺失状态明确标注。
- 月度挂牌租金走势，以及最新已接入月份的一卧、两卧、三卧报价。
- CMHC 年度平均租金：开间、一卧、两卧、三卧及以上和全房型，对照专建出租公寓与业主出租 condo；另列空置率与来源质量。
- 利率、就业、人口，以及按独立屋、半独立屋、排屋、公寓及其他住宅拆分的建设情况。
- 可调整的月供比较（含固定本金／摊还期的历史月供情景）、按当前范围下载 CSV，以及保存含来源版本的本地观察记录。

各数据的覆盖期与最新月份见[来源覆盖](docs/SOURCE_COVERAGE.md)和[工作交接](HANDOFF.md)。

### 使用约定

- 各页按自己的资料频率选择期间：人口与 CMHC 租赁采用独立年度控制，挂牌租金采用独立月份控制。
- 缺失期间保留空白，不补值；同比变化用中性颜色显示，不自动判为利好或利空。
- 筛选和月供输入在当前网页会话中切换页面后保留。

### 覆盖的房价相关因素

| 因素 | 已接入 | 已知的未覆盖／限制 |
| --- | --- | --- |
| 价格 | TRREB HPI 基准价（按房型） | — |
| 交易与供需 | 成交、挂牌、库存月数、成交／新挂牌比 | — |
| 租赁 | 月度挂牌租金；CMHC 年度平均租金与空置率 | 实际成交租金未接入；部分地区（如 Downtown、Richmond Hill／Aurora）尚无独立月度数据 |
| 利率与融资 | BoC 政策利率、国债、新增固定按揭利率；月供情景 | 按揭资料更新滞后 |
| 需求背景 | 就业、人口（年度） | — |
| 新增供给 | 建设开工／竣工／在建（按房型） | 纯 condo 预售／未吸纳库存缺合适输入 |
| 预测 | — | 领先信号规则、历史发布时点、样本外回测均未完成 |

### 解读时的注意事项

- 月度租金来自挂牌报告，不是 MLS 实际成交租金；CMHC 平均租金的同比不是同样本租金涨幅。
- 位置点只用于选择，不代表统计边界；地区数值不下推到街道。不同来源／地区边界不拼接，缺月不补值。
- “来源未提供”不等于官方没有；“抑制发布”是来源不公布该数值，不是导入失败，也不是零。
- 数据状态只核查已存档资料，不证明官网没有更新。
- ⓘ 说明的是影响机制与适用限制，不是预测结论。
- 验收证据、按揭资料延迟、预售来源及历史发布时点等限制见[项目验收表](docs/PROJECT_ACCEPTANCE.md)和[工作交接](HANDOFF.md)；地区、房型与调查口径在相应页面分别标注。

- **分工**：长期定义（目标、范围、指标口径、数据结构、验收标准）以项目规格为准；进度以工作交接为准；验证证据见项目验收表和工作交接。实际运行结果用于验证进度，不得仅凭交接中的历史记录宣称当前代码或数据已验证。

- **证据分工**：覆盖范围以来源覆盖表为明细依据，HANDOFF 保留带日期的状态摘要，验收表保留各次检查的结果与范围。README 不重复易过期数字；必要的证据数字不删除，摘要变更时同步核对相关文档。

## 术语

- **MVP**：第一个可使用的版本。
- **季调**：排除常见季节波动。
- **回测**：使用历史资料检验规则；**样本外**指用建模时没用过的历史区间来检验。
- **领先**：待验证的目标，不是产品名称已证明的能力。
- **信息集／修订可用时点**：预测某一时点时，当时实际已公布、可用的数据（含之后被修订前的版本）。
- **TRREB**：Toronto Regional Real Estate Board，多伦多地区房地产局；**HPI**：MLS® 房价指数；指数与基准房价是不同量，页面分别按实际单位展示。
- **SNLR**：成交／新挂牌比（sales-to-new-listings ratio）。
- **BoC**：加拿大央行；**StatsCan**：加拿大统计局；**CMHC**：加拿大抵押贷款和住房公司，年度租赁市场调查的来源。
- **CMA**：Statistics Canada 的人口普查都会区；后缀年份（如 CMA2021）为所依据的边界年份。
- **共同基期**：多条序列使用同一个起点计算累计变化；**共同期间**：比较使用相同的起止期。
- **抑制发布**：来源出于保密或可靠性等原因不公布该数值。
